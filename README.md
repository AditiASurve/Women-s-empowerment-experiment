# Do empowered women invest more in livestock health?

Replication code and data for the lab-in-the-field experiment in Kenya.

## How to run the analysis

1. Download the repository and extract `Data.zip`.
2. Run `python -m pip install -r requirements.txt` from the repository folder.
3. Open `publication_code.ipynb` and fill in the paths:

   - Cell 2 — Enter the path to the `Empowerment_data` folder.
   - Cell 4 — Enter the paths to `County.shp` and `AHIL_baseline_data_household.csv`.
   - Cell 5 — Enter the paths to `pilot_full.csv`, `ahil_enrollment.csv`, and `stratified.csv`.

4. Run all cells from top to bottom.
